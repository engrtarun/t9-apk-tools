The ritual

You shouldn't have to unlock your phone every time.

Every stale hotspot session turns into the same small ceremony: unlock, find settings, toggle Airplane mode, wait, toggle it back, check the address. Then do it again in fifteen minutes.

T9 APK Tools exists to remove that loop. It schedules the cycle, performs it, and records what the network actually gave you.

The constraint: Android does not let an ordinary app flip Airplane mode silently. That is why this app needs either a one-time ADB grant or an AccessibilityService. There is no hidden shortcut, and no root.

Setup

Four steps. One of them is a single command.

Pick one engine. You do not need both the ADB grant and the Accessibility service. The timer behaves the same either way; only the way the radio gets flipped changes.

No root at any point. USB debugging is a normal developer setting. The grant can be revoked with ADB, or removed by uninstalling the app.

  1. 01

    Install the APK

    Download the current build from this page. Android will ask you to allow installs from your browser; that prompt is normal for a direct APK.

    Android 8.0 or newer. The package is dev.t9.apktools.

  2. 02

    Grant direct-write access Recommended

    Connect the phone, enable USB debugging, then run this once from a computer with ADB installed. It grants WRITE_SECURE_SETTINGS to this app only.

    adb shell pm grant dev.t9.apktools android.permission.WRITE_SECURE_SETTINGS

    Survives reboots. Revoke it later with the same command using revoke instead of grant.

  3. 03

    Or enable the Accessibility service

    No computer needed. Open Settings → Accessibility → T9 APK Tools and turn the service on. The exact menu name varies by OEM.

    An accessibility service can observe and control the screen. Android will show a serious permission dialog. Grant it only to a build you trust.

  4. 04

    Arm the timer

    Set the window — 15 minutes is the default — and press Arm. Keep the hotspot on. Run one manual cycle first so you know how your phone behaves before trusting it unattended.

    Long sessions: keep the charger connected and exempt the app from aggressive battery optimisation.

The runbook

What happens on reset.

Eight steps, in order. The only fixed number is the three-second dwell; the network wait ends when data reports back, or when the attempt times out.

Reset sequence Airplane dwell fixed at 3 s
  1. 01

    Wake

    The scheduled job runs. With the ADB engine the display can stay off.

  2. 02

    Unlock check

    Accessibility mode verifies the keyguard is clear. If not, it aborts and logs it.

    Accessibility only
  3. 03

    Capture IP

    Reads the current public address from a small external IP endpoint.

  4. 04

    Airplane ON

    Writes the setting or performs the toggle. Mobile data and hotspot drop.

  5. 05

    Hold 3 s

    A fixed dwell gives the carrier session time to expire.

    3 seconds
  6. 06

    Airplane OFF

    Restores the radio state and starts waiting for the network.

  7. 07

    Wait for data

    Polls connectivity until mobile data returns, with a timeout instead of forever.

  8. 08

    Capture IP

    Reads the address again and logs before → after. A repeat address is a valid result.

Timing is deliberately unambitious: three seconds is long enough for most carrier sessions to expire and short enough to keep the hotspot outage brief. It is not a guarantee — which is why the app checks the address afterwards.

Nothing hidden

The honest limits.

This automates a setting you could change by hand. It does not defeat carrier policy, tariff limits, or CGNAT. If one of these is a dealbreaker, better to know now.

  • L01 / CGNAT

    A different IP is not guaranteed.

    Carrier-grade NAT can hand back the same public address. Retry, wait longer, or switch mobile data off and on. The app logs what it saw; it will not pretend the address changed.

  • L02 / Hotspot

    The hotspot may drop.

    Airplane mode takes the radios down. Android or your OEM may not restore the hotspot automatically. Expect to re-enable it after a cycle, especially on the first try.

  • L03 / Keyguard

    Accessibility mode needs an unlocked screen.

    If the keyguard is up, the service cannot drive Settings. The cycle is skipped and written to the log. The ADB grant has no such requirement.

  • L04 / OEM variance

    Settings layouts vary.

    Accessibility automation follows labels and positions that Samsung, Xiaomi, and others like to move. Direct mode avoids the UI entirely, which is why it is recommended.

  • L05 / Not a VPN

    It does not hide your traffic.

    Nothing is tunnelled or encrypted by this app. Your carrier still sees the connection; the app only asks for a new network session.

  • L06 / Scope

    No root. No telemetry. No magic.

    No superuser, no account, no analytics. IP checks go to a public endpoint and the result stays in the on-device log. Carrier rules still apply.

Independent utility. Not affiliated with Jio, Google, or any carrier. Use it within your plan and local rules.

Questions

Asked before installing.

Short answers, including the ones that make the app sound less impressive than a landing page usually does.

Something not covered?

Open an issue on GitHub (opens in a new tab)
Do I need root?

No. Direct mode uses a one-time ADB grant of WRITE_SECURE_SETTINGS — a normal Android permission, not superuser. Accessibility mode needs no computer at all. Neither unlocks the bootloader or flashes anything.

Is this a React Native app?

No. The app is native Kotlin/Java. An AccessibilityService has to be a native Android component, so the reset path has no WebView and no JavaScript bridge. That also keeps the APK around two to three megabytes.

Will my public IP always change?

No. CGNAT may hand back the same address; retry or switch data off/on. The carrier decides. The app records the address before and after the cycle so you can see what happened instead of guessing.

What happens to my hotspot?

Airplane mode turns the radios off, so the hotspot will usually drop during the three-second dwell. Some devices restore it afterwards; some do not. Check after your first reset and turn it back on if needed. If a timer on your hotspot turns it off automatically, disable that timer.

How much battery does it use?

Little at idle: a scheduled wake-up and a short radio cycle, not a polling loop or a VPN tunnel. Aggressive OEM battery managers can delay background work, so exempt the app from battery optimisation if resets arrive late.

Is WRITE_SECURE_SETTINGS safe to grant?

It is a powerful permission: it can change protected system settings, though it is not root. Grant it only to a build you trust, and check the SHA-256 first. To remove it:

adb shell pm revoke dev.t9.apktools android.permission.WRITE_SECURE_SETTINGS
How do I uninstall it cleanly?

Turn the Accessibility service off first, then uninstall the app. If you used ADB mode, revoke the grant with the command above; uninstalling also removes it. Your hotspot and network settings stay as they were.
