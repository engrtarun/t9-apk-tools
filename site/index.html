NO ROOT • ACCESSIBILITY AUTOMATION

Change your public IP without touching Airplane mode.

T9 APK Tools arms a 15-minute countdown, toggles Airplane mode at the end, and checks the public address before and after. Built for Jio hotspot sessions that need a fresh carrier mapping — not a VPN, not root.

01 THE PROBLEM

The toggle is easy. Remembering it every 15 minutes is not.

Jio puts hotspot users behind carrier-grade NAT. A session can hold the same public mapping for hours, so the workaround became a manual routine.

The public IPv4 address a website sees belongs to the carrier, not the phone. When a session needs a new network path, the usual fix is to force the radios to reconnect.

By hand, that means Airplane mode on, waiting for the radios to drop, turning it off, waiting for mobile data, restoring the hotspot, and repeating the whole thing 15 minutes later. It ties up the phone and is easy to miss.

The app cannot choose your address. It can time the toggle, perform it, and record whether the address actually changed. The carrier still decides.

MANUAL RESET6 STEPS
  1. 01Turn Airplane mode on
  2. 02Wait for the radios to drop
  3. 03Turn Airplane mode off
  4. 04Wait for mobile data
  5. 05Restore the hotspot
  6. 06Repeat every 15 minutes

Phone nearby. Screen on for UI automation. No guarantee the address changes.

03 SETUP

Three steps, one optional command.

Install the APK, grant Direct access or enable Accessibility, then arm the timer. Direct needs a computer once. The accessibility engines do not.

  1. 01

    Install the APK

    Start here

    Download the APK from this page or GitHub Releases, allow installs from your browser or file manager, then open it. Play Protect may warn about an app it does not recognize; review the source before continuing.

    Go to the download section
  2. 02

    Grant Direct access

    Recommended

    Enable USB debugging (or Android wireless debugging), connect once, and run this from a terminal on the computer:

    Terminal
    $adb shell pm grant dev.t9.apktools android.permission.WRITE_SECURE_SETTINGS

    The grant survives reboots and app updates. It is removed when you uninstall the app. No computer? Skip this and enable Settings → Accessibility → T9 APK Tools instead. That path needs the screen on and unlocked.

  3. 03

    Arm the timer

    About a minute

    Allow notifications and exact alarms, set the countdown (15:00 by default), choose Auto, and start. Set the app to Unrestricted in battery settings. Leave the phone unlocked if you use Accessibility or Quick Settings.

    Android 13 and later may require allowing restricted settings for a sideloaded app before the Accessibility service can be enabled.

What happens when the timer ends.

The run is visible in a foreground notification. Airplane mode is restored even when the toggle or the IP check fails.

    A second lookup, then a comparison and a local log entry.

05 THE MEMORY

Every run leaves a record you can actually read.

Resets, IP readings, and the activity stream land in an on-device SQLite database. One small file, indexed reads, automatic pruning — not a JSON blob rewritten on every line.

A toggle without evidence is just a toggle. The point of this tool is the honest before → after: what the carrier handed out, when, and whether anything actually moved.

Every reset writes the engine it used, how long it took, and the outcome. Every IP reading keeps the moment it was taken, so comparisons are never guessed from stale values. The History screen lists every run with a NEW IP / SAME / FAILED filter, and tapping a run opens the exact log lines that belong to it.

Insights are computed from the same rows: totals, success rate, the calmest three-hour window for your phone, and a warning when the carrier keeps handing back the same address. Share it all as text, or clear it.

All of it stays on the phone. Share exports plain text. There is no account, no sync, no upload.

06 LIMITS

What it cannot do.

The app is explicit about the parts it does not control. Read these before relying on it for anything important.

01

CGNAT may return the same address.

The carrier decides whether a reconnect gets a new address. CGNAT may hand back the same address; retry or toggle data off/on. Same IP is a normal result, not a failed toggle.

02

The hotspot may drop.

Airplane mode turns off Wi-Fi and the hotspot. Restoring the hotspot is experimental and OEM-dependent. Connected clients may need to reconnect.

03

UI automation needs an unlocked screen.

Accessibility and Quick Settings cannot operate on a locked device. Direct can, though some OEMs still block secure-setting writes in the background.

04

OEM behavior varies.

Settings labels, Quick Settings layouts, and battery restrictions differ across Samsung, Xiaomi, Oppo, Vivo, OnePlus, Realme, and others. Node matching has fallbacks, not a guarantee.

05

It is not a VPN.

No traffic is encrypted, proxied, or hidden; it cycles a radio state. A VPN masks the carrier address and makes a before-and-after comparison meaningless, so turn it off when testing.

06

No root. One optional grant.

Direct uses a documented ADB permission grant, not root. Accessibility uses Android's accessibility framework. Nothing here bypasses carrier controls.

07

No data collection.

No accounts, analytics, ads, or crash reporting. IP checks go to public IP services; results and logs stay on the device. This site sets no cookies and loads nothing from third parties.

07 FAQ

Before you sideload.

Short answers. The README and source cover the deeper details, including failure handling and device-specific notes.

Read the README (opens in a new tab)
Does it need root?

No. The Direct engine needs a one-time ADB grant of WRITE_SECURE_SETTINGS, which is a development permission grant, not root. The Accessibility engine needs the accessibility service enabled, nothing more.

Why native Java instead of React Native?

The core is an Android AccessibilityService: a system-bound service with a manifest declaration, a lifecycle controlled by Android, and direct access to accessibility node trees. JavaScript cannot implement it. React Native would add a bridge and tens of megabytes while still needing the same native service. Native Java keeps the APK small and the permission behavior explicit.

Will the IP change every time?

No. The carrier controls CGNAT assignment. The app automates the toggle and reports whether the address changed. CGNAT may hand back the same address; retry or toggle data off/on.

What happens to my hotspot?

Airplane mode turns it off. The optional hotspot restore is experimental and cannot guarantee that clients reconnect cleanly. You may need to turn the hotspot back on manually.

How does it affect battery life?

It is not an always-on VPN or a persistent scanner. The app schedules an exact alarm and runs a short foreground service when the reset starts. Set battery usage to Unrestricted; aggressive OEM managers can still kill background work.

Is the accessibility service safe?

It is powerful by design: Android grants broad window access while the service is enabled. The app limits inspection and clicks to the Airplane mode flow, keeps data on-device, and stores nothing remotely. Disable the service when you are not using it.

Can I uninstall it cleanly?

Yes. Uninstalling removes the app, its local logs and settings, and the ADB grant. Nothing is stored on a server.

Where does the history go?

Into a small SQLite database on the same phone: the newest 300 log events, 150 reset runs, and 80 IP readings. It prunes itself automatically, you can share it as plain text or clear it from the History screen, and nothing leaves the device.

Why is it not on the Play Store?

It is a niche sideload utility that relies on an optional ADB grant and an accessibility service. Publishing a signed APK through GitHub Pages and Releases keeps distribution simple and auditable.
